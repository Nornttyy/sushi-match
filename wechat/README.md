# 寿司小转台 · 微信小游戏测试版

当前是可导入的本地测试工程，不是已上架的微信小游戏。没有借用其他人的 AppID，也没有创建账号、申请权限或提交审核。

## 导入

1. 在项目根目录执行 `npm ci`、`npm run build:wechat`。本次工作区已生成 `wechat/dist`，可直接使用。
2. 在微信开发者工具中导入此 `wechat` 文件夹，项目类型选择小游戏。配置中的 `touristappid` 仅为游客测试标记，不是真实 AppID；如当前工具不允许小游戏游客模式，需要先申请自己的小游戏 AppID，并填入 `project.config.json`。
3. 进行模拟器检查。有真实 AppID 和开发者权限后，再做手机预览、上传及审核准备。

当前环境未安装微信开发者工具，未完成微信真机验收。已做共享规则单元测试及独立浏览器中的 Canvas / 微信接口模拟测试，不能替代官方工具和真机测试。

## 已适配

- `wx.createCanvas` 与 Canvas 2D 界面，不加载 HTML、CSS、DOM 或 WebView。
- 原版 24 个固定关卡、七格三消、自动合成与出餐、逐关解锁、无尽挑战。
- 主界面分为小店、营业、装修三页，支持底部书签、左右箭头和空白处横滑切换；不改变进度、金币或摆件位置。
- 完整猫咪立绘、现有正式寿司素材、三套店内主题与十四种可拖动/翻转/收起的摆件；支持台面、墙面、地面分类，每页五件，翻页浏览。
- 与网页共用 Q 弹曲线：按压、食材飞入、三消聚拢、合成与接餐回弹；快速插入同类食材时同步重定向飞行落点，动画只在前台推进。
- `wx.getStorageSync` / `wx.setStorageSync` 保存进度、钱包、装饰和静音设置；存储失败显示提示。
- `wx.createInnerAudioContext` 播放本地完整 BGM；触摸、前后台、窗口变化、安全区域和音量开关。
- 加载画面至少 3000ms；资源未准备好不进入，资源失败可重试；点击寿司有整体轻弹反馈。
- 出餐由前台动画帧推进，离开/后台不继续发钱，返回后不重复结算。
- 主包仅代码和加载寿司图，其他正式素材使用 `resources` 分包；旧分件图和废弃探索稿不进入包。没有远程脚本，也不依赖 GitHub 的网络资源。

`build-report.json` 给出实际字节数。构建检查主包 4MiB、总包 30MiB 的预算；仅是工程检查，不代表已获平台审核通过。

## 与网页版本的关系

两端共用 `src/game-core.js`、固定关卡数据及 `src/shop-core.js`，网页版本仍独立可玩。微信中的存档和浏览器存档相互独立，不会自动迁移。微信版目前是第一版独立 Canvas 界面，需要继续做真机排版与性能验收。

没有接入广告、支付、收集个人信息、账号登录或云存档。需要这些能力时，另行确认账号资质、隐私说明、相关规范和审核材料，不会默认添加。

音乐署名在声音设置内的“音乐鸣谢”及资源包的 `assets/audio/CREDITS.md` 中保留；小店页不再提供装修和制作名单快捷按钮，装修统一从底部翻页栏进入。
